# ישיבת ועד בית

משחק דיבורים מסתעף לטלפון: אתה הדייר החדש בדירה 6, והערב הישיבה הראשונה שלך בוועד הבית.
הקטע: **אין קריינות מוכנה**. קודם מקליטים בעצמכם את כל השורות של הדמויות (ואת התשובות שלכם, אם רוצים), ורק אז משחקים.

- 7 דמויות, 88 שורות, 12 סופים, מד שפיות, ותשובות נסתרות שנפתחות לפי מה שעשיתם קודם.
- ההקלטות נשמרות בטלפון (IndexedDB), עם ייצוא וייבוא לקובץ גיבוי.
- PWA: אפשר להתקין כאפליקציה באנדרואיד ובאייפון, ועובד גם בלי אינטרנט אחרי הטעינה הראשונה.
- התסריט הוא JSON אחד שאפשר לערוך מתוך האפליקציה.

## להריץ מקומית

```bash
npm install
npm run dev
```

בנייה לפרודקשן: `npm run build` (התוצאה בתיקייה `dist`).

## להעלות לנטליפיי

1. דוחפים את הריפו ל-GitHub.
2. בנטליפיי: **Add new site → Import an existing project → GitHub** ובוחרים את הריפו.
3. הגדרות הבנייה נלקחות אוטומטית מ-`netlify.toml` (פקודה `npm run build`, תיקייה `dist`, Node 22). לוחצים Deploy.
4. הכתובת שמתקבלת היא HTTPS, וזה חשוב: המיקרופון עובד רק ב-HTTPS.

דרך מהירה בלי GitHub: `npm run build` ואז גוררים את התיקייה `dist` ל-[Netlify Drop](https://app.netlify.com/drop).

## להתקין כאפליקציה בטלפון

**אנדרואיד (כרום):** פותחים את הכתובת, ובמסך הבית של המשחק מופיע כפתור **״להתקין כאפליקציה בטלפון״**. אם לא, בתפריט של כרום (שלוש נקודות) בוחרים **״התקנת אפליקציה״** או **״הוספה למסך הבית״**.

**אייפון (ספארי):** כפתור השיתוף → **״הוסף למסך הבית״**.

אחרי ההתקנה המשחק נפתח בלי סרגל דפדפן, ורץ גם בלי אינטרנט.

## איך משחקים

1. **להקליט שורות**: עוברים שורה־שורה, לוחצים על המיקרופון, מדברים, עוצרים. אפשר להשמיע, למחוק ולהקליט שוב. בהגדרות יש מצב מהיר שקופץ אוטומטית לשורה הבאה שלא הוקלטה.
2. **לשחק**: הכפתור נהיה ירוק כשכל שורות הדמויות מוקלטות. התשובות שלך הן רשות: אם לא הקלטת אותן, הן מופיעות כטקסט.
3. הקשה על המסך מדלגת לשורה הבאה. בהגדרות אפשר לכבות את המעבר האוטומטי (נוח כשמשחקים מול קהל).

## לערוך את התסריט

במסך **תסריט** רואים את כל ה-JSON. המבנה:

```json
{
  "title": "שם המשחק",
  "intro": "טקסט פתיחה",
  "start": "n1",
  "characters": { "shula": { "name": "שולה", "role": "…", "emoji": "👵", "color": "#e07a5f" } },
  "nodes": {
    "n1": {
      "scene": "תיאור הסצנה",
      "lines": [ { "id": "l01", "speaker": "shula", "text": "…" } ],
      "choices": [
        { "id": "c01", "text": "מה אתה עונה", "next": "n2", "sanity": -10, "sets": ["paid"] },
        { "id": "c02", "text": "תשובה נסתרת", "next": "n3", "requires": "paid" }
      ]
    },
    "n3": {
      "scene": "…",
      "lines": [ { "id": "l09", "speaker": "moti", "text": "…" } ],
      "ending": { "title": "שם הסוף", "text": "מה קרה בסוף" }
    }
  }
}
```

- כל שורה ותשובה צריכות `id` ייחודי. ההקלטות נשמרות לפי ה-`id`, אז שינוי `id` מנתק את ההקלטה שלו.
- `sanity` משנה את מד השפיות (מתחיל ב-100).
- `sets` / `clears` מדליקים ומכבים דגלים, ו-`requires` מציג תשובה רק אם הדגל דלוק.
- קובץ ברירת המחדל נמצא ב-`src/data/script.js`.

## מבנה הקוד

```
src/
  App.jsx               ניהול מצב, אחסון, התקנה, ייצוא/ייבוא
  data/script.js        התסריט
  lib/script.js         עזרים לתסריט (דגלים, ספירות, ולידציה)
  lib/audio.js          הקלטה, ניגון, פתיחת אודיו ב-iOS
  lib/storage.js        IndexedDB
  components/ui.jsx     רכיבים משותפים
  screens/              בית, אולפן, משחק, תסריט, הגדרות
```
